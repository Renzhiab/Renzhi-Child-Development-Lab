# 实验室动态稿件字段表

每条动态单独保存为一个 Markdown 文件，文件名按“日期 + 事件”命名，例如：

`20261112实验室网站上线.md`

## 字段表

| 字段 | 是否必填 | 填写规则 | 示例 | 页面位置 |
|---|---|---|---|---|
| `date` | 必填 | `YYYY.MM.DD` | `2026.11.12` | 动态卡片与详情页日期 |
| `category` | 必填 | 只能填：`通知公告`、`学术动态`、`生活动态` | `通知公告` | 动态分类筛选 |
| `tag` | 选填 | 简短标签，不替代分类 | `网站更新` | 详情页分类标签 |
| `icon` | 选填 | 一个 emoji，图片缺失时显示 | `📢` | 图片占位 |
| `image` | 选填 | 相对 `lab-website` 的图片路径或完整网址 | `website-assets/01-brand/logo.png` | 首页动态卡片、详情页主图 |
| `link` | 选填 | 公众号推文或其他文章完整网址 | `https://mp.weixin.qq.com/...` | 详情页“查看原文” |
| `order` | 选填 | 同一天有不止一条动态时的显示顺序；数字越大越靠前，默认 `0` | `3` | 同日期动态排序 |
| `title` | 必填 | 中文标题 | `任智发展实验室网站上线公告` | 卡片、列表、详情页 |
| `titleEn` | 选填 | 英文标题；留空时英文模式继续显示中文 | `Lab Website Launch` | 英文模式 |
| `summary` | 选填 | 一两句话摘要 | `实验室网站现已正式上线。` | 稿件归档 |
| `summaryEn` | 选填 | 英文摘要 | `The lab website is now live.` | 英文模式 |

Markdown 正文放在第二行 `---` 之后。若需要英文正文，在英文内容前单独放一行：

```text
<!-- English -->
```

## 发布步骤

1. 复制 `_动态稿件模板.md`，按“日期 + 事件”重命名并填写内容。
2. 图片放到 `lab-website` 内的合适位置。如果要使用首页同一张图，填写 `website-assets/01-brand/logo.png`。
3. 把稿件保存在 `news_drafts` 文件夹中。
4. 双击 `更新网站动态.cmd`。脚本会检查字段、生成 `updates/03-data/news-data.js`。
5. 刷新或重新打开 `网站.html`，动态即会出现。

`updates/03-data/news-data.js` 是自动生成文件，请勿手工修改。字段或图片路径有误时，更新窗口会提示具体文件和错误原因。
